首个公开测试版本，支持 Android 8.0 及以上。

- 连接 Navidrome，浏览、搜索和管理音乐收藏。
- 同步歌词、队列、离线下载、均衡器与歌曲间淡入淡出。
- 播放缓存、断网恢复及双通道应用更新。
- 深浅模式、主题配色、存储空间管理与通知栏歌词。

已知限制：三星 S25 长时间锁屏和网络切换仍需真机验收；暂不支持 Emby、Plex、ReplayGain、队列跨进程恢复及播放次数回传。

从旧开发版本迁移时，debug 签名与正式签名不兼容。请先保留服务器配置，不要直接清除数据。正常的后续正式版本采用同一签名覆盖更新。
