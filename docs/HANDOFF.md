- 本轮已通过远端 CI 发布 0.1.2 公开测试版；COS、R2 独立镜像均成功。发布提交为 `a6794b0`，S25 未安装本轮测试包。更新记录规范已固化在 [发布文档](RELEASE.md#更新记录写法)。

## S25 退出崩溃

USB 日志确认：SM-S9310 / Android 16，GitHub 0.1.0 在 01:38:04、02:11:49、02:13:44 三次出现 `PlaybackService.onDestroy` 关闭 TLS socket 时的 `NetworkOnMainThreadException`。正常 `REMOVE TASK` 与 `APP CRASH(EXCEPTION)` 是不同退出记录。

连接池清理及请求取消改为串行后台任务；捕获旧请求，避免延迟取消新请求。针对 socket 关闭线程的 MuMu 回归通过。S25 只读获取日志，尚未安装修复版或清除数据，真机复验待执行。

## 验证与边界

- 0.1.2：65 项 JVM、MuMu 11 项定向设备测试、lint 和远端签名构建通过。通用 APK 为 2,925,798 字节（2.79 MiB），SHA-256 `a693ee8d6221d29c562af2da840d4a5898d5cf1c25c0442d886e4cd0784568dc`。证书与 0.1.1 一致，APK 内容审计、源码归档、更新记录与双通道文件摘要核验通过。

- 0.1.1 历史验证：本地 JVM 60 项通过，debug / release 构建及 lint 通过，仍有既有警告。正式签名校验通过，证书与 0.1.0 一致；远端正式包 2,926,442 字节（2.79 MiB），SHA-256 `1a158968cc5e12acdcd61059ecd798094018fbed7bd0a42dd171c5b71a07113d`。连接关闭、紧凑布局通过设备测试；退出生命周期、播放缓存和恢复共 14 项回归通过。原生预览生成另有设备用例。
- 用户确认：S25 连续后台播放 10 首、约 40–50 分钟，无断连卡死；网络切换通过。长暂停恢复不要求真实验收、不作为交付阻碍。
- 退出崩溃修复版、独立长时锁屏、蓝牙切换、小组件及系统媒体胶囊尚无完整真机验收结论。
- 尚未实现：Emby / Plex、ReplayGain、队列拖拽排序、独立用户队列、批量下载管理、启动自动播放及播放次数回传。共享歌单只浏览播放。
- 默认播放缓存 512 MB，可选 1 GB / 2 GB，LRU 淘汰；播放结束不立即删除。清理保留在用缓存及用户下载。

## 镜像保留策略

COS 与 R2 均只保留最新已验证的音乐版本；参考 Lee’s Mail 的先验证再清理顺序。新 APK、源码、校验文件及更新清单通过核验后，才删除文件名精确匹配的旧版资产。GitHub 历史版本保留。清理范围和分页异常的 5 项测试通过。本轮两个通道均已删除 0.1.1 的 APK、源码 ZIP 和校验文件，仅保留 0.1.2；GitHub 历史版本未删除。

远端正式 APK、对应源码、清单、校验文件和 R8 映射已下载到 `artifacts/release/0.1.2` 保存；旧版正式产物仍保留。日志与镜像校验均在内存中处理，未额外生成临时文件。
