## S25 退出崩溃

USB 日志确认：SM-S9310 / Android 16，GitHub 0.1.0 在 01:38:04、02:11:49、02:13:44 三次出现 `PlaybackService.onDestroy` 关闭 TLS socket 时的 `NetworkOnMainThreadException`。正常 `REMOVE TASK` 与 `APP CRASH(EXCEPTION)` 是不同退出记录。

连接池清理及请求取消改为串行后台任务；捕获旧请求，避免延迟取消新请求。针对 socket 关闭线程的 MuMu 回归通过。S25 只读获取日志，尚未安装修复版或清除数据，真机复验待执行。

## 验证与边界

- 本地 JVM 60 项通过，debug / release 构建及 lint 通过，仍有既有警告。正式签名校验通过，证书与 0.1.0 一致；本地精简包 2,928,930 字节，发布包最终摘要以远端产物为准。连接关闭、紧凑布局通过设备测试；退出生命周期、播放缓存和恢复共 14 项回归通过。原生预览生成另有设备用例。
- 用户确认：S25 连续后台播放 10 首、约 40–50 分钟，无断连卡死；网络切换通过。长暂停恢复不要求真实验收、不作为交付阻碍。
- 退出崩溃修复版、独立长时锁屏、蓝牙切换、小组件及系统媒体胶囊尚无完整真机验收结论。
- 尚未实现：Emby / Plex、ReplayGain、队列拖拽排序、独立用户队列、批量下载管理、启动自动播放及播放次数回传。共享歌单只浏览播放。
- 默认播放缓存 512 MB，可选 1 GB / 2 GB，LRU 淘汰；播放结束不立即删除。清理保留在用缓存及用户下载。
