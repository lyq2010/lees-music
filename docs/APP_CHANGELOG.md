# 版本更新

## 0.1.1 · 公开测试版

- 精简依赖中的多余语言资源，保留中文、英文回退及必要运行资源。
- 修复三星 S25 退出应用时，播放服务在主线程关闭网络连接导致的崩溃。
- 保存曲库、首页概览及空歌单，重新打开优先显示本机内容。
- 恢复退出前的播放队列、歌曲、进度和播放模式；重新打开保持暂停。
- 播放封面页支持下滑收起，底部播放条支持左右滑动切歌。
- 新增 1×1、2×2、3×2、4×1 桌面小组件，使用封面背景和原生布局预览。
- 应用更新页增加离线更新记录；补全系统媒体会话封面和应用入口。

验收说明：S25 连续后台播放 10 首、约 40–50 分钟及网络切换已由用户验收通过。退出崩溃修复已通过针对性 MuMu 回归，修复版尚未在 S25 复验；小组件外观及三星媒体胶囊仍待真机确认。长暂停恢复不作为交付阻碍。

## 0.1.0 · 公开测试版

- 支持 Navidrome 音乐库、分类搜索、收藏与歌单。
- 新增同步歌词、播放队列、离线下载与曲风均衡器。
- 支持歌曲间淡入淡出、睡眠定时与通知栏歌词。
- 提供主题配色、深浅模式和存储空间管理。
- 加入播放缓存、断网恢复及双通道应用更新。
- 更新应用图标，精简安装包体积。

S25 连续后台播放及网络切换已通过验收。退出崩溃修复版、小组件与媒体胶囊仍待真机确认。
