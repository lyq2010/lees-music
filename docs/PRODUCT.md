# 产品交互与验收基准

本文件记录官人确认的产品方向与调研依据，不代表下列功能均已实现。

## 参考来源与取舍

- Musiver：自建曲库的信息架构、服务器能力边界、音乐库/发现/搜索/设置的组织方式，以官人提供的 Android 截图为视觉参照。其公开仓库明确不包含应用源码；本项目独立实现。
- Apple Music Android：播放页内切换歌词，同步歌词与纯文本歌词分开处理；歌名、进度和播放操作保持可用。
- Spotify Android：清晰的当前播放入口、独立队列管理、明确区分立即播放/下一首播放/加入队列；操作反馈反映真实播放状态。
- 不照搬商业服务的会员、内容推荐、账号体系。继续保留 Lee's Music 的单地址、自托管、不遥测，以及点歌先打开播放页但不自动出声的既定要求。
- 不根据静态截图推断具体手势或动画时序。官网未明确说明的交互属于本项目设计选择，必须在 MuMu 实测。

## 页面合约

| 页面 | 结构与行为 | 完成标准 |
| --- | --- | --- |
| 音乐库 | 歌曲/专辑/艺术家等分类入口，收藏和歌单承载用户自己的音乐 | 入口进入真实列表；数量、收藏来自服务端；不把演示数据当真实内容 |
| 发现 | 每日推荐、最近添加、最近播放、常听、随机推荐分区 | 区分歌曲与专辑；查看全部、播放、刷新各自完成真实操作 |
| 搜索 | 输入、提交、歌曲/专辑/艺术家分类、结果导航 | 区分未输入/加载/无结果/错误；旧请求不覆盖新搜索；结果可操作 |
| 播放 | 封面与歌词共用歌名、进度、音量及播放控件 | 切换视图不重建队列、不重置进度；切歌、暂停、缓冲和错误状态准确 |
| 歌词 | 上部大字号当前句、弱化前后句、上下渐隐；下部保留播控 | 自动跟随、手动浏览、回到当前句、点句跳转；空白间奏不制造不可见焦点；同时间戳内容成组 |
| 队列 | 当前曲和接下来播放分明，新增/移除/排序有明确作用范围 | 编辑队列不误删服务器文件，不改变正在播放曲目的位置与身份 |
| 设置 | 按播放/网络/存储/外观等职责分组 | 每个开关有实际效果且可恢复；未完成项不伪装成已经保存成功 |
| 服务器 | 能力匹配、输入校验、探测结果、账号与缓存隔离 | 失败不串库，不泄露凭据；切换后旧请求不污染当前页面 |

## 歌词本轮验收

- 查看歌词时播放控制可直接使用，和封面页共用组件及真实播放器状态。
- 行宽、换行与字号以参考图的主次关系为准，不固定用“前两行”推算位置；长行也要居中且不截断。
- 手动拖动只浏览，不跳歌、不抢回滚动；通过明确入口恢复跟随。点有时间戳的行才跳转，普通歌词不提供假跳转。
- 时间偏移在显示与跳转中一致；向前/向后 seek 都能重新定位。
- 同时间戳的原文/其他文本成组，不自行翻译或制造逐字时间轴。
- 区分加载、无歌词、未选曲、失败；失败可重试；返回当前歌曲时复用已读取歌词。
- 使用 MuMu 做交互自动化与实际截图检查；构建、单元测试通过不等于完成产品验收。

## 2026-09-26 播放器与队列对照

参考 [Spotify 当前播放](https://support.spotify.com/is-en/article/now-playing/) 的随机、循环、队列和更多入口，以及 [Apple Music 安卓队列](https://support.apple.com/en-ie/109336) 的接下来播放及队列管理。采用适合本地曲库的行为，不照搬商业推荐。

- 封面和歌词页共享歌曲菜单、随机/循环、缓冲状态及队列入口。循环顺序为关闭 → 列表 → 单曲。到达队列末尾后点击播放可重播当前曲目。
- 队列按 Media3 Timeline 的真实随机顺序显示，一次只列一轮；列表循环将前段列入接下来，单曲循环明确提示。之前的队列不是收听历史，不宣称其中歌曲已播放。
- 只在待播曲目提供调整顺序/移除，清空需二次确认，当前曲身份与进度保留。移除播放队列不删除文件。
- 随机模式下手动重排暂不可用。明确插入“下一首”或追加队列时，固定现有随机顺序并关闭随机模式，反馈说明这一变化，确保明确入队的顺序兑现；这一点是本产品当前实现取舍，不声称复刻 Spotify/Apple 的独立用户队列。
- 睡眠定时已提供 5/15/30/45/60 分钟、剩余时间和取消。以经过时间倒计时，切歌/暂时暂停不重置；到时暂停并保留队列。由当前播放服务持有，不作为跨服务销毁/进程重启的系统闹钟。暂不提供“本曲结束”选项。
- 拖拽排序和独立用户队列仍为后续项。

## 设置与状态保持的当前实现

- 设置采用分组入口：播放、网络、存储、个性化与系统相关功能；设置子页返回保留原滚动位置。
- 个性化支持系统/浅色/深色及四种强调色，立即生效并持久化；播放页保持深色。
- 存储管理展示播放缓存、封面磁盘/内存与下载占用。播放缓存默认 512 MB，可选 1 GB / 2 GB，达到上限自动淘汰旧缓存；手动清理二次确认后执行，保留在用播放缓存，不影响离线音乐或账号。
- 音量淡入淡出为自动换曲时 3 秒交叉淡化，默认关闭；暂停和手动定位立即结束过渡，保留用户音量。下一首未准备好时正常换曲。
- 通知歌词开关控制系统媒体会话艺术家行的同步歌词，无同步歌词回退；三星特有通知呈现仍待实机验证。
- 服务器卡片统一呈现类型、地址、账号、当前状态及编辑/连接操作，先验证后激活。
- 首页空歌单也是有效缓存结果，不因再次进入闪成加载或空白；首次加载、失败、确认无歌单各有独立状态。
- 所有导航页面统一避让系统安全区域；MuMu 检查通过不替代 S25 真机验收。
- 播放速度属于播放页操作，封面与歌词页均可调整；不再提供跳过静音。选项描述仅保留必要、正式、简洁的说明。

- 均衡器预设：均衡（默认）、流行、摇滚、爵士、古典、电子。均衡保持平直，其他预设采用温和曲线并同步应用至交叉淡化两路播放器。
- 播放可靠性已接入整曲预取、断点续传、长暂停重新加载与网络恢复续播；恢复保留当前歌曲和进度，主动暂停后不自动恢复，重试耗尽显示明确提示。三星长时锁屏、真实网络切换与代理超时仍需专项验收。
