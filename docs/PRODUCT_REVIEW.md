# 发布前产品检查

参考 [Spotify 离线播放](https://support.spotify.com/us/article/listen-offline/)、[Spotify 播放队列](https://support.spotify.com/us/article/play-queue/)、[Apple Music 队列](https://support.apple.com/en-ie/109336) 和 [Apple Music 淡入淡出](https://support.apple.com/en-la/105067)。
比较目标是自建音乐库的日常体验，不包含商业曲库、订阅、社交推荐或其他厂商专属设备协议。

| 项目 | 当前结果 | 后续验收 |
| --- | --- | --- |
| 曲库、搜索、收藏、歌单与歌曲操作 | 已接入；列表缓存、空状态及失败重试有回归测试 | 持续检查大曲库和真实服务器权限差异 |
| 歌词 | 时间同步、手动浏览、点击跳转 | 不同服务端歌词数据 |
| 队列 | 下一首、追加、移动与移除 | 拖动排序、进程重启后恢复尚未实现 |
| 已下载歌曲 | 本次补齐普通列表和操作菜单优先使用离线文件 | 下载完成后断网实测 |
| 连续播放 | 当前及下一首预取、断网等待恢复、暂停后重建连接、交叉淡化 | S25 长时间锁屏与 Wi-Fi/移动网络切换 |
| 设置 | 外观、均衡器、通知歌词、网络策略、缓存管理 | S25 系统权限及通知样式 |
| 更新 | 双通道清单、摘要及签名校验、系统安装确认 | 首次正式签名版本与下一版本完整升级链 |
| 播放历史 | 读取服务器最近与常听记录 | 尚未提交本机收听记录；不能宣称播放次数同步已完成 |
| 音量均衡 | 曲风均衡器预设 | ReplayGain 尚未实现 |

仍存在以上明确限制，不能将“已接入”或自动化通过写成全部生产验收完成。初始版本应按实际测试范围发布，真机验收通过前不宣传完整适配 S25。
